# Nuxt 3 Public Starter

A minimal **Nuxt 3** project deployed to Vercel.

## Overview

A clean starter Nuxt 3 application with an `app.vue` entry point and a `server/` directory for API routes or middleware. Useful as a base for Vue-based server-side-rendered apps.

## Repository Structure

```
├── app.vue       # Main app entry
└── server/       # Server routes / middleware
```

## Tech Stack

Nuxt 3, Vue, TypeScript, Vercel.

## Status

Starter / small deployment.
